Website Cửa Lò Travel - GitHub Pages

Để xuất bản tại https://khanhhoang2604.github.io/:
1. Tạo repository tên chính xác: khanhhoang2604.github.io trong tài khoản khanhhoang2604.
2. Giải nén ZIP này và tải index.html, thư mục css, images lên thư mục gốc của repository.
3. Commit changes.
4. Vào Settings > Pages, chọn Deploy from a branch, branch main, folder /(root), Save.

Giữ nguyên cấu trúc:
index.html
css/style.css
images/*.avif
